# 03 - Architecture Design

This phase is driven by the "Architect Agent" of the BMAD framework. It focuses on defining the technical architecture of the AEM solution.

## Artifacts in this Phase

- **system-architecture.md**: This document provides a high-level overview of the system architecture, including AEM services, integrations, and data flows.
- **component-design.md**: This file contains the detailed design for the AEM components, including their Sling models, dialogs, and HTL scripts.
