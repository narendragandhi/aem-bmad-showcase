# User Stories

This document contains user stories that describe the desired functionality from the perspective of different user roles.

## As a Content Author

- I want to be able to easily create a new marketing page using a pre-defined template so that I can quickly launch new campaigns.
- I want to be able to drag and drop components onto a page to build out the content.
- I want to be able to preview my changes before submitting them for approval.
- I want to be able to upload images and other assets to a central library.

## As a Marketer

- I want to be able to personalize the homepage hero banner based on the user's country.
- I want to be able to run A/B tests on the "Request a Demo" button to see which color converts better.
- I want to be able to view analytics reports on page performance directly within AEM.

## As a Website Visitor

- I want to be able to view the website on my mobile phone.
- I want the website to load quickly.
- I want to be able to easily find the information I'm looking for.

## As a Developer

- I want a CI/CD pipeline that automatically builds and deploys my code to a development environment so that I can quickly test my changes.
- I want the CI/CD pipeline to run automated tests and code quality checks to ensure that my changes don't break the build.
- I want to be able to easily access logs from the AEM environments to debug issues.
- I want to be able to deploy my changes to production through a controlled and automated process using Cloud Manager.

## As a QA Engineer

- I want to be able to test new features in a dedicated staging environment that is a replica of production.
- I want to be able to run automated regression tests to ensure that new changes don't break existing functionality.
- I want to have a clear process for reporting and tracking bugs.
- I want to be able to perform performance and security testing before a release.
- I want to be able to validate that the application is working as expected in production after a deployment.
