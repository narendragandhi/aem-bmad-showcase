# 02 - Model Definition

This phase is about defining the structure of the content and the overall organization of the website. This is a critical step in any AEM project.

## Artifacts in this Phase

- **information-architecture.md**: This document outlines the sitemap and navigation structure of the website.
- **content-models.md**: This file defines the content models for the AEM templates and components. It specifies the fields and their types for each component and page template.
