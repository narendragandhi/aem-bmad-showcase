# AEM as a Cloud Service Greenfield Implementation using BMAD Method

This project showcases the BMAD (Breakthrough Method for Agile Development) for a greenfield implementation of Adobe Experience Manager (AEM) as a Cloud Service.

## Overview

The BMAD method is an AI-driven agile development framework. This project provides a structured approach to using BMAD for AEM projects, from initial business discovery to deployment.

## Project Structure

- **/bmad**: Contains all documentation and artifacts related to the BMAD process, organized by phases.
- **/src**: This directory would contain the actual AEM project source code, typically generated from the AEM project archetype.

## The BMAD Phases for AEM

The `/bmad` directory is organized into the following phases:

1.  **00-Project-Initialization**: Setting up the AEM project and development environment.
2.  **01-Business-Discovery**: Gathering business requirements, defining user stories, and establishing project goals.
3.  **02-Model-Definition**: Creating content models, defining the information architecture, and designing templates and components.
4.  **03-Architecture-Design**: Defining the overall system architecture, including integrations, security, and caching strategies.
5.  **04-Development-Sprint**: Executing development sprints, including coding, unit testing, and code reviews.
6.  **05-Testing-and-Deployment**: Conducting quality assurance, performance testing, and deploying to AEM as a Cloud Service.

## How to Use This Showcase

Each folder within the `/bmad` directory contains a `README.md` file that explains the purpose of that phase and the documents it contains. You can use this structure as a template for your own AEM projects, adapting it to your specific needs.
